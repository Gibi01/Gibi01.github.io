# Hospital Ripper — TP Desarrollo de Software

Aplicación web para consultar especialidades y profesionales, reservar turnos médicos y gestionar agendas y asistencia.

**Autor:** Gobbo Facundo — legajo 52288. Trabajo individual autorizado por el docente. La propuesta adopta un alcance equivalente a dos integrantes.

## Proyecto

- [Frontend](frontend-dsw/): React, TypeScript, Vite y Material UI.
- [Backend](backend-dsw/): Express, TypeScript, MikroORM y MySQL; autenticación mediante Better Auth.
- [Documentación](docs/README.md).
